Data Availability

The archived digital-twin simulation outputs, trained random-forest surrogate
models, model-testing inputs, and analysis scripts supporting the computational
analyses in this study are publicly available in the associated GitHub
repository: [INSERT GITHUB REPOSITORY URL].

The repository provides frozen surrogate models for the five soybean cultivars
evaluated in this study (DN251, DN252, DN253, HN48, and HN51), together with
compact test data and step-by-step instructions for loading the models and
reproducing model inference. Large raw 3D mesh files are not required for the
provided reviewer model test.
